# SGeMS Workbench for QGIS

Export projected QGIS well and borehole point layers, preview samples and run ordinary kriging or sequential simulations. The bundled modelling workers run on 64-bit Intel/AMD Linux. The QGIS plugin requires QGIS 3.34–3.x.

Install the plugin ZIP using **Plugins → Manage and Install Plugins → Install from ZIP**, enable **SGeMS Workbench**, and open it from **Plugins → SGeMS**.

See the [workbench guide](sgems_export/README.md) for input preparation, supported algorithms, assumptions and build instructions. Third-party notices are included with the engine.
